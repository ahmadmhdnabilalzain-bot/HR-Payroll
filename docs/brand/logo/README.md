# Mubinflow wordmark options

Typographic wordmarks (no symbol), written "MubinFlow" with a capital M
and F for readability; the product and domain are typed "Mubinflow".
Each SVG is outlined paths (no font needed) in a light-background
(dark ink) and a dark-background (light ink) version.

| File prefix | Direction |
|---|---|
| 01-montserrat-bold | Geometric bold, tight (Emaar-like) |
| 02-montserrat-two-weight | "Mubin" bold + "Flow" light |
| 03-outfit-semibold | Open geometric |
| 04-urbanist-bold | Friendly geometric |
| 05-sora-semibold | Technical |
| 06-redhat-extrabold | Heavy, high impact |
| 07-jost-wide | Wide-tracked, Futura feel (luxe) |
| 08-cinzel-luxe | Classical serif, capitals + small caps (Damac-like) |
| 09-syncopate-caps | All caps, wide (reference only) |

`generate-wordmarks.py` rebuilds them (needs fonttools and the
@fontsource fonts). Fonts are open-licence (SIL OFL) from Fontsource;
confirm each licence before the final logo is registered. Tracking is
tuned by eye; hand-kerning and any custom letter detail come after the
owner picks a direction. Not a trademark clearance.
