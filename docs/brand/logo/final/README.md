# Mubinflow logo: chosen direction (owner, 2026-11-26)

Option 2: "Mubin" in Montserrat Bold plus "Flow" in Montserrat Light,
written MubinFlow (capital M and F for readability; the product is
typed Mubinflow). Pure typography, outlined to vector paths.

Files: `mubinflow-wordmark-{ink,paper,black,white}.svg`,
`mubinflow-monogram-{dark,light}.svg` (rounded tile with the M),
`favicon.svg`, `favicon-{16,32}.png`, `app-icon-{180,512}.png`,
`preview.png`. `generate-final.py` rebuilds everything.

Colours: ink #10151c, paper #f4f6f8 (brand accent not chosen yet).
Rules (provisional): clear space around the wordmark = the height of
the lowercase "n"; minimum wordmark width 96 px (use the monogram
below that); never change the weights, the case or the spacing; use ink
on light and paper on dark, black or white for single-colour print.

Open items: the Montserrat fonts are SIL OFL from Fontsource (confirm
the licence text before registration); spacing is tuned by eye; no
trademark clearance has been done (UAE register search is still to do).
